# Security policy

Please report vulnerabilities and **privacy leaks** (any case where pdf-toolkit prints, logs,
uploads or publishes data it should have hidden) privately, through GitHub's
"Report a vulnerability" button on the repository's Security tab. Do not open a public issue and
do not attach real documents: describe the case with synthetic data.

Only the latest release is supported.

Out of scope: vulnerabilities of Stirling-PDF itself (report them to
[Stirling-Tools](https://github.com/Stirling-Tools/Stirling-PDF/security)), and data that cannot
be detected by design (see "Limits" in docs/privacy-model.md).
